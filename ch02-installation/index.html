專案安裝與設定

建立開發與執行環境，讓您在一分鐘內完成 drawio-cli 的部署。

系統需求

在安裝 drawio-cli 之前，請確認您的系統環境符合以下要求：

  • Node.js：建議安裝 v18.0.0 或更新之長期支援（LTS）版本。
    • 由於本專案完全基於 ESM 模組系統，且測試套件需要執行非同步 ESM 模組載入，因此執行測試時需要 Node.js 的實驗性功能支援（--experimental-vm-modules）。
  • 作業系統：支援 Windows、macOS 與 Linux。
  • 套件管理工具：npm v9.0.0+（隨 Node.js 一併安裝）。

安裝步驟

請依照下列指示，在本地完成專案設定：

1. 取得專案原始碼並進入目錄

cd C:\VSCode_Proj\Draw_io_cli

2. 安裝依賴套件

在專案根目錄下，執行 npm 安裝指令以獲取包括 commander 等在內的必要依賴套件：

npm install

安裝完成後，您會看到目錄下新增了 node_modules 資料夾，且終端機回報已成功安裝所有依賴項。

ℹ️
本地執行測試

若要確認安裝無誤且核心範本功能正常，您可以執行 npm test 執行內建的 36 個測試案例。詳細說明請參見第 7 章。

全域快速指令設定（選用）

預設情況下，您必須在專案根目錄使用 Node 指令來執行 CLI：

node bin/draw-cli.js --help

如果您希望能夠在作業系統中的任何目錄、任何路徑，直接像執行系統指令一樣使用 draw-cli，可以使用 npm 的軟連結功能：

# 必須在專案根目錄（C:\VSCode_Proj\Draw_io_cli）下執行
npm link

執行之後，npm 會將 package.json 中定義的 bin 項目（指向 bin/draw-cli.js）註冊至系統的全域執行路徑中。此後，不論您在哪個資料夾，都可以直接執行：

draw-cli --help
💡
如何解除全域連結？

若未來您想取消這個全域命令連結，只需在專案目錄下執行 npm unlink 即可恢復原狀。
