模板系統設計

解析 Draw.io 的底層 XML 規範，避免發生「無效圖表」載入錯誤。

Draw.io XML 結構剖析

一個標準的 .drawio 檔案本質上是 XML。其骨架結構如下： 

<?xml version="1.0" encoding="UTF-8"?>
<mxfile host="draw-cli" version="1.0.0">
  <diagram name="圖表名稱" id="diagram-unique-id">
    <mxGraphModel dx="1000" dy="600" grid="1" ...>
      <root>
        <!-- 0 與 1 為固定保留節點 -->
        <mxCell id="0" />
        <mxCell id="1" parent="0" />

        <!-- 這裡存放您的自訂元件與連線 -->
        <mxCell id="node1" value="標籤" style="..." vertex="1" parent="1">
          <mxGeometry x="100" y="100" width="120" height="60" as="geometry" />
        </mxCell>
      </root>
    </mxGraphModel>
  </diagram>
</mxfile>

XML 撰寫的四大關鍵鋼鐵規則

在設計代碼生成 XML 時，若不遵守以下規定，Draw.io 會直接損毀並顯示「非圖表檔案 / Cannot open file」的警告。

規則 1：特殊字元強制轉義（Escape）

在 value="..." 屬性或 style="..." 屬性內，凡是含有 & 字元，必須轉義為 &amp;。

  • 例如：value="AI Agent Q&A" 在寫入 XML 時必須轉換為 value="AI Agent Q&amp;A"。
  • 同理，< 與 > 也建議轉義為 &lt; 和 &gt;。

防錯小撇步：

強烈建議在產生字串時，使用簡易的安全轉義函式處理：

function escapeXml(str) {
  return str.replace(/&/g, '&amp;')
            .replace(/</g, '&lt;')
            .replace(/>/g, '&gt;');
}

規則 2：換行字元的正確寫法

在節點 value 的文字內容中若需要換行，禁止使用 <br>、\n 或 \r\n。 必須強制轉義為 XML 的實體換行編碼：&#xa;。

  • ❌ 錯誤：value="第一行\\n第二行" 或 value="第一行<br>第二行"
  • ✅ 正確：value="第一行&#xa;第二行"

規則 3：啟用 HTML 標籤支援

如果您需要在節點內使用富文字樣式（例如使用 <b>粗體</b> 或 <i>斜體</i>），則該節點的 style 欄位內必須顯式包含 html=1; 屬性。 

<mxCell id="myNode" value="<b>重要</b>指標" style="rounded=1;html=1;..." vertex="1" parent="1">

規則 4：容器與相對座標系統（Parent-Child）

在架構圖中，如果有多個節點被框在某個泳道（Swimlane）或容器（Container）內，則定位機制會發生根本性改變：

  • 頂層節點：其 parent 屬性必須設為 "1"。幾何座標 x, y 為相對於整個畫布左上角的絕對座標。
  • 子節點：若節點隸屬於某個容器（例如容器的 id="L3"），其 parent 屬性必須指向該容器的 id（即 parent="L3"）。此時，其 geometry 座標 x, y 必須變更為相對於該容器左上角的相對座標！
  • 跨容器的連線（Edges）： 雖然連線是從容器 A 的節點指向容器 B 的節點，但是連線本身的 parent 屬性仍應設為 "1"，並透過 source 與 target 屬性指定兩端點節點的絕對 id 即可。
💡
開發建議

在設計大型架構圖時，建議先以「靜態」的紙筆畫出大略的容器與節點分配，並用簡單的相對偏移量（如 containerX + offsetX）在 JavaScript 程式碼中計算座標，這樣能大幅減少手工維護坐標出錯的機率。

如何新增自訂模板

drawio-cli 採用「模板即函式」的設計，每個範本對應 src/templates/ 下的一個獨立 .js 檔案。 新增自訂模板只需三個步驟：

步驟 1：建立模板檔案

在 src/templates/ 目錄新增一個 JavaScript 檔案，並導出一個標準生成函式：

// src/templates/my-diagram.js
export function myDiagramTemplate() {
  const escapeXml = (s) =>
    s.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;');

  // 使用反引號 template literal 組裝 XML 字串
  const label = escapeXml('Hello & World');
  return '<?xml version="1.0" encoding="UTF-8"?>' +
    '<mxfile host="draw-cli" version="1.0.0">' +
    '<diagram name="My Diagram" id="my-diagram-001">' +
    '<mxGraphModel dx="1200" dy="800" grid="1" pageWidth="1654" pageHeight="1169">' +
    '<root>' +
    '<mxCell id="0" />' +
    '<mxCell id="1" parent="0" />' +
    `<mxCell id="box1" value="${label}" style="rounded=1;whiteSpace=wrap;html=1;fillColor=#dae8fc;strokeColor=#6c8ebf;" vertex="1" parent="1">
  <mxGeometry x="100" y="100" width="200" height="80" as="geometry" />
</mxCell>` +
    '</root></mxGraphModel></diagram></mxfile>';
}

步驟 2：在 generator.js 中註冊

打開 src/generator.js，在頂部匯入新模板函式，並加入 templates 對照表：

// src/generator.js
import { aiAgentTemplate } from './templates/ai-agent.js';
import { myDiagramTemplate } from './templates/my-diagram.js'; // 新增匯入

const templates = {
  'ai-agent': {
    fn: aiAgentTemplate,
    description: 'AI Agent 系統架構圖 (5層泳道)',
  },
  'my-diagram': {                        // 新增條目
    fn: myDiagramTemplate,
    description: '我的自訂圖表範本',
  },
};

步驟 3：驗證執行

完成後，執行以下指令確認新模板已正確註冊並可產生檔案：

# 確認列表中有新模板
draw-cli list

# 測試產生
draw-cli generate my-diagram ./test-output.drawio

常用 Style 屬性速查

Draw.io 的節點外觀完全由 style 字串控制。以下是最常用的屬性一覽：

屬性說明範例值
rounded圓角矩形0 / 1
fillColor填充色（十六進位）#dae8fc
strokeColor邊框色#6c8ebf
fontStyle字型樣式0=一般 1=粗體 2=斜體
fontSize文字大小（px）11 / 13
align水平對齊left / center / right
verticalAlign垂直對齊top / middle / bottom
whiteSpace文字換行wrap 啟用自動換行
html啟用 HTML 標籤1
swimlane泳道容器加在 style 最前面
startSize泳道標題列高度30 / 35
dashed虛線邊框1
⚠️
Style 字串格式注意事項

Style 屬性使用分號（;）分隔，且最後一個屬性後面不需要加分號（但加了也不會出錯）。屬性值中若有特殊字元同樣需要 XML 轉義。
