基本指令用法

掌握 CLI 命令的執行方式與參數，輕巧產出各類架構圖。

基本語法與指令清單

如果您尚未執行 npm link，需要進入專案根目錄並透過 node 執行入口檔案：

node bin/draw-cli.js <command> [args]

若已執行 npm link，則可在系統任意處執行：

draw-cli <command> [args]

指令 1：列出所有可用圖表範本

使用 list 指令可以列出目前專案內建的所有圖表範本與說明：

draw-cli list

輸出結果：

Available templates:
  ai-agent          AI Agent 系統架構圖 (5層泳道)
  ai-agent-heatmap  AI Agent 系統架構圖 (熱力圖著色版)
  9x9-comparison    9×9 流程對比表 (4×4 網格，深藍/青綠色調)
  9x9-heatmap       9×9 熱力圖對比表 (4×4 網格，藍綠色帶)
  9x9-dashboard     9×9 儀表板卡片表 (4×4 網格，Tableau 強調色)
  doodle-flowchart  Doodle 手繪風流程圖 (Sketch 效果，中英雙語標籤)
  color-schemes     10 種配色方案參考表 (2 欄 × 5 列佈局)

指令 2：產生圖表檔案

使用 generate 指令來根據特定的範本產生 .drawio 檔案。

指令格式

draw-cli generate <template> [output_path]
  • <template>：必填。為上述 list 中列出的 Command Key。
  • [output_path]：選填。產出檔案的路徑與檔名。如果未提供，預設會在當前目錄下輸出 <template>.drawio。

實戰範例

範例 1：以預設檔名在當前目錄產生 AI Agent 架構圖

在當前目錄下生成 ai-agent.drawio 檔案：

draw-cli generate ai-agent

範例 2：指定產出檔名與目錄

將 AI Agent 架構熱力圖產生到指定的 ./build/agent-flow.drawio：

draw-cli generate ai-agent-heatmap ./build/agent-flow.drawio

若 ./build/ 目錄不存在，CLI 會自動遞迴建立它，避免拋出找不到資料夾的錯誤。

範例 3：透過參數選項（Option）指定輸出路徑

您也可以使用 -o 或 --output 參數來指定路徑：

draw-cli generate doodle-flowchart -o C:\diagrams\my-doodle.drawio

指令結構樹

以下樹狀圖呈現 draw-cli 的完整指令架構與參數分支：

draw-cli
├──
list
印出所有可用範本與說明
└──
generate <template>
根據範本產生 .drawio 檔案
├──
[output_path]
選填，預設：./{template}.drawio
└──
-o / --output <path>
與 [output_path] 等效
💡
如何檢視說明？

執行 draw-cli --help 或 draw-cli generate --help 可隨時呼叫指令的詳細規格與說明。
